\# 🥬 FreshSense AI



FreshSense AI is an intelligent perishable inventory intelligence platform developed as part of the TCS AI Sprint.



The system combines data engineering, machine learning, recommendation systems, Retrieval-Augmented Generation (RAG), and AI agents to help reduce food spoilage and improve inventory management.



\---



\# Features



\- Data Cleaning Pipeline

\- Feature Engineering

\- Demand Forecasting

\- Spoilage Prediction

\- Smart Recommendation Engine

\- Knowledge Base using RAG

\- AI Assistant

\- Monitoring Dashboard
